# Data Schema Reference

This document defines the JSON structures used by the supply-chain-prober skill.

---

## `session_context.json`

Created by `deploy.sh` for each respondent. Updated by the agent during and after the session.

```json
{
  "session_id": "probe_JohnDoe_20260629_103000",
  "respondent": {
    "name": "John Doe",
    "email": "john@acme.com",
    "role": "Procurement Manager",
    "company": "Acme Corp"
  },
  "created_at": "2026-06-29T10:30:00Z",
  "completed_at": null,
  "status": "pending | in_progress | completed | abandoned",
  "question_bank": "references/question_bank.md",
  "responses_file": "responses.json"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `session_id` | string | Unique identifier. Format: `probe_{SafeName}_{Timestamp}` |
| `respondent` | object | User metadata from the deployment CSV |
| `created_at` | string | ISO 8601 UTC. Set by `deploy.sh` |
| `completed_at` | string\|null | ISO 8601 UTC. Set by the agent when session ends |
| `status` | enum | `pending` → `in_progress` → `completed` or `abandoned` |

---

## `responses.json`

An array of response objects. Each entry represents one question-answer pair collected during the session.

```json
[
  {
    "question_id": 10,
    "category": "Procurement & Sourcing",
    "question": "Do you rely on a single supplier for any critical material?",
    "answer": "Yes — one company in Gujarat for friction material.",
    "confidence": "high",
    "risk_flags": ["single_source_dependency"],
    "follow_up": false,
    "timestamp": "2026-06-29T10:04:58Z"
  }
]
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `question_id` | integer | yes | Matches the question number in `question_bank.md`. Use `0` for agent-generated follow-ups. |
| `category` | string | yes | The category heading from the question bank |
| `question` | string | yes | The exact question as asked to the user |
| `answer` | string | yes | The user's response, verbatim but lightly cleaned for readability |
| `confidence` | enum | yes | `high` (clear, specific), `medium` (vague), `low` (guessing) |
| `risk_flags` | string[] | no | Zero or more flags from the risk taxonomy (see SKILL.md Step 4) |
| `follow_up` | boolean | no | `true` if this question was generated by the agent, not from the bank |
| `timestamp` | string | yes | ISO 8601 UTC when the answer was recorded |

---

## `master.json` (output of `collect_responses.py`)

The aggregated dataset across all sessions.

```json
{
  "collected_at": "2026-06-30T08:00:00Z",
  "total_respondents": 87,
  "total_responses": 1421,
  "completion_rate": "87.0%",
  "risk_summary": {
    "single_source_dependency": 34,
    "manual_process": 52,
    "no_visibility": 41,
    "frequent_disruption": 28,
    "compliance_gap": 12,
    "no_continuity_plan": 19
  },
  "sessions": [ ... ]
}
```
