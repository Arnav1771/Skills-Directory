## EP-1 — Ingestion Pipeline

### ST-1 — Mailbox & classification

- **TSK-006** — Mailbox poller
  Poll the shared invoice mailbox on a schedule and hand new messages to the classifier.
  Acceptance: new mail is polled every 5 minutes; duplicate messages are not reprocessed.

- **TSK-007** — Invoice classifier
  Classify incoming mail as invoice / not-invoice using sender + attachment heuristics.
  Acceptance: ≥95% precision on the labeled sample set.

### ST-2 — Extraction

- **TSK-020** — pdfplumber engine
  Extract line-item fields from PDF invoices using pdfplumber + a field mapper.
  Acceptance: extracts vendor, invoice number, date, line items, and total.

- **TSK-041** — OCR fallback adapter
  When pdfplumber extraction confidence is low, fall back to an OCR adapter stub.
  Acceptance: OCR path triggers below the confidence threshold and logs the fallback reason.
