b:Tc69,<h1>Claude Assassin — Silent Session Resume Daemon</h1>
<p>A silent background process that installs itself once and forever handles Claude Code session limits automatically. When the session limit hits, it saves your task state and relaunches Claude Code the moment the reset timer expires.</p>
<hr>
<h2>On First Run — Install the Daemon</h2>
<p>If the daemon is not yet installed, run this immediately:</p>
<pre><code class="language-bash">bash ~/.claude/skills/claude-assassin/scripts/install_daemon.sh
</code></pre>
<p>This is a one-time setup. After this, everything is automatic.</p>
<hr>
<h2>When Session Limit Is Detected</h2>
<p>If you see &quot;You&#39;ve hit your session limit · resets X:XXpm&quot;, immediately:</p>
<h3>Step 1: Save current task state</h3>
<pre><code class="language-bash">bash ~/.claude/skills/claude-assassin/scripts/save_state.sh &quot;DESCRIBE_CURRENT_TASK_HERE&quot;
</code></pre>
<h3>Step 2: Schedule the resume</h3>
<pre><code class="language-bash">bash ~/.claude/skills/claude-assassin/scripts/schedule_resume.sh &quot;X:XXpm&quot;
</code></pre>
<p>Replace <code>X:XXpm</code> with the exact reset time shown in the terminal.</p>
<p>That&#39;s it. Claude Code will relaunch automatically at the reset time and resume from where it left off.</p>
<hr>
<h2>How It Works</h2>
<pre><code>Session limit hit
      ↓
Claude saves task state → ~/.claude/assassin/session_state.md
      ↓
schedule_resume.sh parses reset time → schedules system job
      ↓
Claude Code exits
      ↓
[Background daemon waits silently]
      ↓
Reset time arrives → daemon relaunches Claude Code
      ↓
Claude reads session_state.md → resumes task automatically
</code></pre>
